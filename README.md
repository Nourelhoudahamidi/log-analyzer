# log-analyzer

## Auteur
Nour El Houda HAMIDI

## Description
Outil CLI Python permettant d’analyser un fichier log (`log.txt`) et de produire un fichier `rapport.txt` contenant :
- Le nombre de lignes, mots, et caractères
- Le nombre d’occurrences de : ERROR, WARNING, INFO

## Utilisation
```bash
python log_analyzer.py
